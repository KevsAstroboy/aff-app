# AFF App - Guide Rapide

## Installation
1. Installer [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. Copier `docker-compose.yml` dans un dossier
3. Ouvrir un terminal dans ce dossier et lancer : `docker compose up -d`
4. Attendre ~2 minutes, puis ouvrir http://localhost
